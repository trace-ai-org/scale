Add a source

A publication, patent, thesis or report (PDF or DOI), a data file (CSV or Excel) or a graph file. SCALE reads it into a private graph you explore here, with the same code as scale add-source.

Private: everything runs in this browser and nothing is uploaded to SCALE; a private graph is never contributed. A model reads something only with your own key: a paper's text when you curate it, a table's column names only if you ask.

Curate a source

A paper, patent or report, as a PDF. SCALE turns it into a graph and checks every quote against the source. It takes a few minutes.

  • Free. No API key. Signing in with GitHub gives the service only your login.
  • Private. The graph comes back to you only. It is published only if you click Contribute, for a person to review.
  • Read by a model. The source's text goes to the SCALE service and the model provider it runs on.
  • Deleted after the job, unless it is openly licensed or you tick Keep below.
More details
  • A kept copy is private to the service, used only to curate the source again when SCALE's schema changes. You can withdraw your agreement at any time, which deletes it.
  • Contributing opens a public pull request on github.com/trace-ai-org/scale under your GitHub login. The records are shared under CC BY 4.0 and quote no text of a source in copyright. Once merged, your login joins the contributors' leaderboard.
  • When you are signed in, the leaderboard counts which contributions answered your questions (a digest of your login and the day, never the question).
  • A rights holder can ask for a source's records or kept copy to be removed by opening an issue.

Contributors to catal-commons

Everyone who has added a source to catal-commons, SCALE's shared catalysis graph, scored by the knowledge they added (evidence-backed triples) and by how often it answers other people's questions. Each entry is a merged pull request, read from contributors.yaml.

How scoring works

The rules are one function, tools/commons.py; changing them is a pull request.
